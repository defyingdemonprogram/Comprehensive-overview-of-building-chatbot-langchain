## Comprehensive Overview of Building Chatbots with LangChain

This project provides a comprehensive overview of building chatbots using **LangChain**, inspired by the **DeepLearning.AI** LangChain course.

Additionally, this repository includes lab materials from the **NVIDIA RAG Course**—a highly practical and in-depth course focused on building robust, production-ready Retrieval-Augmented Generation (RAG) applications.


## Repository Structure

* **Notebooks**:

  * [`Data_Loader_And_Splitter.ipynb`](./Notebooks/Data_Loader_And_Splitter.ipynb): Demonstrates how to load and split data for downstream tasks.
  * [`Vectorstores_and_Embeddings.ipynb`](./Notebooks/Vectorstores_and_Embeddings.ipynb): Covers embedding generation and storing/retrieving them using vector databases.

* **[RAG\_with\_Neo4j](./RAG_with_Neo4J/)**:
  Introduces Neo4j and shows how to enhance RAG applications using graph databases to leverage relationships within the data.

* **[Similarity Search](./Similarity%20Search/)**:
  Explores similarity search techniques, including FAISS and traditional methods like TF-IDF and BM25—often considered the GOAT of classical information retrieval algorithms.

* **[NVIDIA RAG Course Lab](./NVIDIA-RAG-Course/)**:
  Hands-on labs from NVIDIA’s course on building production-ready RAG systems. A must-see resource for going beyond MVPs and into real-world deployment.
